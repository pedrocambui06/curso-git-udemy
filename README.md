# Git & GitHub Course | Matheus Battisti - Hora de Codar | Udemy

This repository was created with the goal of documenting the knowledge acquired throughout the course "Git e GitHub do básico ao avançado (c/ gist e GitHub Pages)", covering everything from fundamental concepts to more advanced practices used in day-to-day work.

Access the project: https://curso-git-udemy.vercel.app

## Main Content Covered
* Fundamental commands: ```git init, git clone, git add, git commit, git push, git pull```
* Branch management: ```git branch, git checkout, git switch, git merge```
* Advanced commands: ```git rebase, git stash, git reset, git reflog, git clean, git gc, git fsck```
* Conflict resolution
* Conventional Commits writing technique

## GitHub Concepts
* Creating and managing repositories
* Using **Issues** to organize tasks
* Workflow with **Pull Requests**
* **Code Review** process
* Creating a **Wiki** for documentation
* Project management with **GitHub Projects**
* Team collaboration using best practices
* Code sharing with **Gists**

## Portfolio with GitHub Pages
During the course, a simple portfolio was built using **HTML and CSS**, applying versioning and collaboration concepts, with the project organized into different **branches** to represent development stages, use of **Pull Requests** to integrate changes, **Issues** for task management, the **Projects** tab for workflow organization, and the use of **tags** to record versions. In the end, the project was published with a simple deploy using **GitHub Pages**, making the portfolio accessible online.

## Documentation with Markdown
* Structuring README.md files
* Writing clear and professional documentation
* Using headings, lists, links, images, and code blocks

## Basic Website Hosting Concepts
* Fundamental web hosting concepts
* Difference between domain and server
* Types of hosting (static and dynamic)
* Publishing and making websites available online
* Introduction to the deploy process
